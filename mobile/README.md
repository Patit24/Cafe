# Mobile Attendance App

Expo app for employee profile selection, face-verification flow, and duty timer.

## Environment

Copy `.env.example` to `.env` and set:

- `EXPO_PUBLIC_API_URL`: deployed NestJS API URL.

Physical devices cannot use `localhost`; use a reachable LAN URL for local testing or the deployed backend URL.

## Commands

```bash
npm install
npm run start
npm run android
npm run ios
npm run lint
```
